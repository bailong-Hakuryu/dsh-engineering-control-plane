# Role Agents receive Kernel-built Prompt Packages

Every Role Agent receives a Kernel-built Prompt Package that separates immutable host and role instructions from Mission Contract, Plan, Assignment, canonical Evidence, and explicitly labelled untrusted repository content. It binds Mission, Attempt, Role Run, Workspace Fingerprint, and content digests; a parent Agent cannot supply hidden authority or override the frozen capability model. Role Agents inherit neither the parent conversation nor another child transcript. Cross-role information must first become validated canonical Evidence, while Execution Traces remain human navigation and diagnostics only.

Context selection is deterministic and recorded in a Context Manifest ordered by Contract, active Decisions, Plan, Assignment-required Evidence, then auxiliary Evidence. Included, summarized, retrievable, omitted, and truncated material is explicit. Required content that cannot be supplied intact prevents execution or satisfaction of its Assurance Requirement; large materials may be retrieved only through gated read capabilities, never silently forgotten.
