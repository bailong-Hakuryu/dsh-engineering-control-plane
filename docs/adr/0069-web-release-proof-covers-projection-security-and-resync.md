# Web release proof covers projection security and resync

Web release tests cover whole-snapshot Projection revisions, gap detection and resynchronization, canonical Decision Message composition, stale Frontier conflicts, Principal and Session Binding checks, read-only paginated detail access, missing Execution Trace degradation, and untrusted Evidence rendering including XSS payloads. Component and contract tests are supplemented by a browser smoke against the Packed Installation, so successful TypeScript compilation or screenshots alone cannot establish client compatibility.
