# Normative documents use host-resolved references

`mission_start` may add external documents to the Mission Contract only through Specification References that the Harness Adapter resolves from the current user's authorized attachments or repository scope and proves were explicitly designated normative. The model cannot supply arbitrary paths or URLs; contents are budget-checked and published as digest-bound Evidence before acceptance. This preserves rich document-driven Missions without making every attachment normative or granting path-selection authority to model text.
