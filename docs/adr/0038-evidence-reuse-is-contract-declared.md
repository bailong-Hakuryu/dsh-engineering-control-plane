# Evidence reuse is Contract-declared

Evidence may cross an Attempt boundary only when its registered Evidence Contract declares that class reusable and every validity dependency digest remains exact. Reuse produces canonical Evidence Derivation linking source and consuming Attempts; digest equality alone is insufficient. Mission Contract, Effective Policy, Provider, Registry, Plan, Workspace, or toolchain changes invalidate Evidence according to the Contract, while implementation integrity, verification integrity, specification conformance, repository standards, and Action Ledger integrity are recaptured by default for every Attempt.

Operationally failed Assurance Assignments are not silently retried. Parallel siblings first settle and publish useful Evidence, then the Mission blocks; explicit Resume may append replacement Role Runs only for failed or indeterminate Assignments within the frozen Assurance Execution Budget. Valid completed Assessments may remain usable when their declared dependency digests are unchanged, and all replaced runs remain immutable history.
