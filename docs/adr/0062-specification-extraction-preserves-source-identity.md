# Specification extraction preserves source identity

An authorized Specification Reference first binds the original artifact identity and digest within Artifact Budget. Model-readable Extraction Evidence separately records extractor identity and version, media type, source location mapping, warnings, and truncation while retaining integrity linkage to the original. Unsupported or unreliable extraction blocks normative use instead of pretending that the model consumed the document; extracted text alone never replaces the source artifact as specification identity.
