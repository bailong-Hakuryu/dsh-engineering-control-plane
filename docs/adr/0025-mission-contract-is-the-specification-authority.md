# Mission Contract is the specification authority

Spec conformance is evaluated against a revisioned Mission Contract consisting of objective, acceptance criteria, constraints, active User Decisions, normative Input Records, and explicitly designated specification Evidence. Ordinary context and traces are informative, while Plan remains a subordinate implementation strategy that cannot override the Contract; any conflict blocks for resolution. This avoids treating all conversation text as normative without reducing the Mission to whatever happens to exist in repository documentation.
