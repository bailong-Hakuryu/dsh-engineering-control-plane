# Security remediation cannot bypass Mission Rework

When DSH Security Assurance participates in a Mission, its Assessment Kernel remains read-only and its Remediation Workflow may contribute a bounded Patch Artifact or verification plan but cannot acquire the Repository Write Lease or apply changes directly. A Developer Role in an explicitly requested Rework Attempt owns implementation, and the resulting immutable Subject requires a new security Assessment before the Finding may be considered resolved.
