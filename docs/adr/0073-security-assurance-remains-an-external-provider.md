# Security Assurance remains an external provider

DSH Security Assurance is a separately versioned companion product integrated through the Control Plane's Assurance Provider boundary rather than embedded in the Kernel. It may submit security Evidence claims and a non-authoritative Security Verdict through an Assurance Submission, but the Kernel validates the submission, owns the resulting Assurance Assessment and Assurance Result, and remains the sole writer of the Quality Gate and Mission disposition.
