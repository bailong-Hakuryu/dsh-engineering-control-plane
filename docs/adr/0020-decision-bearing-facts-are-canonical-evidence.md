# Decision-bearing facts are canonical Evidence

Repository, environment, dependency, or execution observations that affect a User Decision, Plan, Assurance Plan, Action Gate, or Quality Gate must be published as canonical Evidence with source, producer, time, Repository Identity, Workspace Fingerprint, digest, and integrity state. Incidental navigation may remain only in an Execution Trace, but stale, corrupt, or workspace-mismatched facts cannot continue to support a decision; this pays bounded storage cost to prevent agent prose from becoming hidden authority.
